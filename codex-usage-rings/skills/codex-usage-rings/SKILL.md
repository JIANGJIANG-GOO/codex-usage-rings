## 用量圆环

安装或更新优先运行仓库/安装包根目录的 Install.ps1；-DownloadLatest 会下载并校验最新 Release。默认固定安装位置为 %LOCALAPPDATA%\CodexUsageRings\app，检查其中 install-result.json 的注册与运行结果。管理已安装程序时，优先使用该目录下 codex-usage-rings 的脚本；自定义安装目录可从 CodexUsageRings 计划任务的 Execute 和 WorkingDirectory 确认，程序名必须为 CodexUsageRings.exe。不要无意从插件缓存目录启动另一份程序。无固定安装时，本技能目录向上两级是插件根目录。按用户要求运行根目录的脚本：

- 启动：`Start.ps1`。后台启动无边框圆环，不修改 Codex 安装文件。
- 登录自启：`AutoStart.ps1` 注册当前用户独立计划任务；`AutoStart.ps1 -Remove` 取消。已有任务时 Start.ps1 核对程序路径、工作目录和参数，旧路径会先修复再启动。
- 停止：`Stop.ps1`。只通知本圆环进程退出。
- 查看状态：`Status.ps1`。读取状态和运行进程；不要把启动成功当成已成功定位。
- 重建：只有用户要求修改程序或可执行文件缺失时运行 `Build.ps1`。

圆心为 7d / 5h，外环为剩余额度：大于 15% 绿色，小于等于 15% 红色。7d 灰色虚线表示未知；5h 无有效数据时隐藏。内圈与头像直径一致。所有模型选中 Ultra 思考强度后显示紫白流动渐变，可靠识别 Fast 开启时显示多点快速流光，不依赖思考强度或是否工作。重启浮层后需展开模型菜单一次读取开关；此后保留同一聊天已确认的状态。数据来自当前 Codex app-server；不要读取或导出 auth.json，不得自动使用重置卡或调用购买接口。0.4.0 支持用户在圆环面板中手动选卡，并通过“重置→确认”二次点击执行重置；开发和诊断仅查询或使用模拟服务，不消耗真实卡片。

程序在 Codex 窗口可见且账户按钮定位可靠时显示，失去前台焦点不隐藏圆环；最小化或隐藏宿主时隐藏。状态中 `anchorFound=false` 时先看 `anchorReason`。实际自动定位依赖当前版本的辅助功能树；不要改成桌面固定像素来假装完成自动对齐。

脚本若受到沙箱限制，按工具的正常审批流程运行；不要修改权限设置。启动不需要重启 Codex，插件目录注册后的发现可能需要用户下次重启应用。

0.2.8 使用 Windows 原生子窗口，status.json 的 embedded 表示已核对父窗口关系。此方式不是官方嵌入式插件接口；不修改宿主文件。

点击 7d 或有效的 5h 圆环打开重置卡列表。确认间隔严格大于 0.5 秒，10 秒后取消；关闭面板或换卡也取消。只有用户亲自完成确认才调用重置，按钮处理中禁止重复提交。
